# Active Directory

Tooling for Active Directory accounts, groups, Group Policy and reporting.

| Project | Description |
|---|---|
| [AD-Server-Report](AD-Server-Report/README.md) | Exports enabled Windows Server computer accounts from multiple domains to Excel and HTML |
| [AGPM-Scheduler](AGPM-Scheduler/README.md) | Schedules the deployment of already checked-in Advanced Group Policy Management (AGPM) GPOs |
| [gMSA-GUI](gMSA-GUI/README.md) | WPF GUI for creating group Managed Service Accounts and checking who can retrieve their passwords |
| [Group-Owners](Group-Owners/README.md) | Fills in the owner of each access group in a CSV from its AD membership |
| [Keytab-Generator](Keytab-Generator/README.md) | Windows Forms GUI around `ktpass` for generating Kerberos keytab files |
