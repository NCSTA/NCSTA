# Keytab Generator

Windows Forms GUI that wraps `ktpass` to generate Kerberos keytab files for Active Directory service accounts.

## Requirements

- Windows PowerShell 5.1
- `ActiveDirectory` module (RSAT)
- `ktpass` available on the machine, or on a domain controller you can remote to
- `kinit` on the path if you want the keytab validated after it is created (optional)

## Setup

The domain dropdown is empty by default. Add your domains to the `$domains` list near the top of the script:

```powershell
$domains = @(
    'contoso.com'
    'emea.contoso.com'
)
```

To have the tool send its notification email, also set `SmtpServer` in the mail parameters. It is blank by default.

Keep real domain and mail server names out of the public copy of this repository.

## Usage

```powershell
.\KeytabGenerator.ps1
```

| Field | Purpose |
|---|---|
| Select Domain | Domain of the service account; also used as the Kerberos realm |
| SAMAccountName | Account the keytab is generated for |
| Password | Account password passed to `ktpass` |
| Email Address | Recipient of the notification for the request |
| Ticket # | Reference number for the request |
| Keytab Encryption | `AES256-SHA1` |
| Keytab Principal | `UPN`, or `SPN Based` with an SPN such as `HTTP/name.domain.com` |

**Generate Keytab** runs `ktpass` and writes the file. **Generate Command Only** produces the `ktpass` command line without running it.

## Behavior

- A UPN keytab is generated by running `ktpass` locally.
- An SPN-based keytab is generated on a discovered domain controller and mapped to the account with `/mapuser`. The realm is appended to the SPN when it is not supplied.
- When `kinit` is available the new keytab is tested. If the test fails, the keytab is deleted and no notification is sent.

## Output

`C:\Temp\Keytabs\<SAMAccountName>.keytab`. The folder is created if it does not exist.

## Notes

For an SPN-based keytab, `ktpass /mapuser` sets the account's password and changes its user principal name to the SPN, which invalidates any existing keytab for that account. Coordinate with the application owner before generating a keytab for an account that is already in use.
