# Tools

General server and file share administration tooling.

| Project | Description |
|---|---|
| [Archive-Files](Archive-Files/README.md) | Moves files and folders listed in a CSV into a mirrored archive tree, with scripts to restore them |
| [Retire-Public-Share](Retire-Public-Share/README.md) | Migration toolkit that retires a public share by moving its data to an archive while keeping the folder skeleton browsable |
| [Server-Retirement](Server-Retirement/README.md) | Phase 1 dependency audit that checks a server for active connections before retirement and emails the owning team |
