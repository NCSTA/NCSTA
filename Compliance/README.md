# Compliance

Audit, hardening and vulnerability-scan tooling for Windows servers.

| Project | Description |
|---|---|
| [Certificate-Metadata](Certificate-Metadata/README.md) | Collects per-certificate PKI metadata from Windows servers over WinRM into selectable objects |
| [Crypto-Inventory](Crypto-Inventory/README.md) | Remotely collects cryptographic posture data from Windows servers over WinRM |
| [Nessus-Merge](Nessus-Merge/README.md) | Merges individual Nessus scan exports into one master workbook per zone and server role |
| [Resolve-SID](Resolve-SID/README.md) | Determines whether unresolved SIDs (STIG WN22-00-000450) are orphaned or belong to an unreachable domain |
| [Server-Protocol-Audit](Server-Protocol-Audit/README.md) | Read-only module that checks a server's SSL/TLS protocol status and cipher-suite order, with Schannel hardening rollout documentation |
| [Server-QA-Checker](Server-QA-Checker/README.md) | WPF tool that validates Windows server build state against JSON templates |
| [Windows-Audit](Windows-Audit/README.md) | Modular Windows configuration audit that produces auditor-compatible reports |
