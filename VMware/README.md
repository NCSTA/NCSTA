# VMware

PowerCLI tooling for vSphere inventory, templates and VM maintenance.

| Project | Description |
|---|---|
| [Template-Patching](Template-Patching/README.md) | Monthly clone, patch and promote cycle for templates, plus a read-only scan for orphaned template folders on datastores |
| [VM-Hardware-Tools-Upgrade](VM-Hardware-Tools-Upgrade/README.md) | Paste-ready scripts that stage VM hardware version 21 upgrades and report VMware Tools status for Windows Server VMs |
| [VM-Location-Report](VM-Location-Report/README.md) | HTML report of where Windows Server VMs run, with host socket and core counts for licensing reviews |
