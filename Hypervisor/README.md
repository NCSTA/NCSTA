# Hypervisor

Hyper-V and SCVMM tooling, including VMware to Hyper-V migration.

| Project | Description |
|---|---|
| [Commvault-HyperV-PostMigration](Commvault-HyperV-PostMigration/README.md) | Pre- and post-migration automation for Commvault-driven VMware to Hyper-V migrations: NIC and route capture, vNIC setup and guest networking over PowerShell Direct |
| [ESXi-to-HyperV](ESXi-to-HyperV/README.md) | Captures a VM's network identity from vCenter before migration and reapplies it through SCVMM and PowerShell Direct afterwards |
| [SCVMM-V2V-HighAvailability](SCVMM-V2V-HighAvailability/README.md) | Converts a single VMware VM through SCVMM V2V and enables high availability on the result |
